# Speed Check

Небольшая консольная программа на Python для измерения скорости скачивания данных по HTTP/HTTPS.

## Требования

- Python 3.6 или новее
- Подключение к интернету

Дополнительные библиотеки устанавливать не нужно.

## Запуск

Откройте терминал в папке проекта и выполните команду:

    python main.py https://example.com

Вместо https://example.com укажите адрес ресурса, данные которого необходимо скачать.

Пример:

    python main.py "https://speed.cloudflare.com/__down?bytes=10000000"

## Возможности

- Выполнение 10 последовательных HTTP-запросов.
- Полное скачивание тела каждого ответа.
- Измерение времени каждого запроса.
- Расчёт среднего времени запроса.
- Подсчёт общего объёма скачанных данных.
- Расчёт средней скорости скачивания.

## Результат работы

Программа выводит:
- Время каждого запроса.
- Объём скачанных данных.
- Среднее время запроса.
- Общий объём скачанных данных.
- Среднюю скорость скачивания.

## Единицы измерения

Скорость измеряется в MB/s (мегабайтах в секунду).

1 MB = 1 000 000 байт.

Формула расчёта:

    Скорость = Общий объём данных / Общее время скачивания / 1 000 000

## Обработка ошибок

Программа обрабатывает HTTP-ошибки, ошибки подключения и превышение времени ожидания ответа.

## Примечание

Результат зависит от выбранного сервера, состояния сети и размера файла. Поэтому показатели могут отличаться при повторных запусках.
